# ByteSpace

## Tech Stack

- React
- Vite
- Tailwind CSS
- React Router

## Getting Started

```bash
npm install
npm run dev
```

## Scripts

| Command           | Description                  |
| ----------------- | ---------------------------- |
| `npm run dev`     | Start the development server |
| `npm run build`   | Build for production         |
| `npm run preview` | Preview the production build |
| `npm run lint`    | Lint with oxlint             |
| `npm run format`  | Format with Prettier         |
